# 多种子平均的统计与频谱分析

本方案在本轮 11 PDE 的多种子评估完成、查看汇总前记录。每个 PDE 固定 ID 1500–1531，种子 0、1、2，100 步联合重建。调参使用 ID 1100–1103，与这 32 个物理输入分离；Burgers 只评价完整轨迹 u。

1. 对每个物理输入、每个物理场先平均三份预测，再独立计算相对 L2 误差。多通道场（RD、SWE、Wave）对整个 a 或 u 向量场求范数，保留所有通道；不合并 a/u。
2. 主比较是三样本均值对预先指定的单次预测 seed 0。另报告三次单样本误差的平均作为单次采样风险的描述估计。后者受范数凸性约束，不能把必然非增当作独立的显著性发现。
3. 表中分别报告 seed 0、三次单样本误差均值、三预测均值的误差均值和样本 SD。SD 的独立单位是 32 个物理输入，不是 96 次运行。对三预测均值减 seed 0 的逐输入差给出配对 bootstrap 区间（20,000 次固定随机种子）。
4. 对 11 PDE 的 21 个场给出点态 95% 区间，以及 Bonferroni 调整的区间（每个区间覆盖水平 1-0.05/21）。只有调整后区间上端小于零时，才描述为本组比较下有显著降低的证据。小样本 bootstrap 区间是近似推断，不声称精确总体覆盖。
5. 频谱分析同时展示参考能量、预测能量和误差能量。周期二维场用空间 FFT；非周期二维场用 DCT；Burgers 只沿空间方向 FFT 并对物理时间平均，避免将时间频率误称为空间频率。多通道场先按通道求频域能量再求和，零真值通道的预测误差不丢弃。
6. 频段报告全参考能量归一化的误差贡献；频段相对误差仅在该输入的参考频带能量达到全场能量的 1e-14 时定义。保留低频、过渡频率和高频结果，不把噪声底附近的比值解释为真实高频恢复能力。频谱效应作为描述性分析，不追加未经声明的显著性结论。
7. 计数必须达到 11×32×3=1056 个预测，真值、掩码在同一输入的三个种子间相同。复核每个结果哈希、物理单位、误差、NFE，以及平方误差的均值/方差恒等式。采样平均增加至 3 倍调用成本；不作为训练种子稳定性或精确后验均值的证据。

实现核对补记（2026-09-08）：这里的种子 0、1、2 指抽样编号；实际采样种子为 `20260912 + 10000 * draw_index + input_id`，观测种子仅依赖输入编号。

频谱实现修正（2026-09-08，完整分析时）：最初的非周期映射遗漏了 Reaction–Diffusion 的零 Neumann 边界和 Shallow Water 的开放边界，曾在开发预览中对它们使用 FFT。按第 5 条既定规则，完整结果将这两类场改为 DCT-II；依据是冻结配置中的 `boundary_condition_mode`，不是频谱效果。该修正不改变预测、全场误差或配对置信区间。非周期类为 Poisson、Helmholtz、Darcy、Reaction–Diffusion、Shallow Water、Steady Heat。
