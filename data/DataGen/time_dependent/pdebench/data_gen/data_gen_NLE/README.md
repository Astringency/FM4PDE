## Data Generation

### FM4PDE 2D Reaction-Diffusion Generator

The 2D reaction-diffusion data used by FM4PDE is generated by:

```text
data/DataGen/time_dependent/pdebench/data_gen/src/sim_diff_react.py
data/DataGen/time_dependent/gen_rd.py
```

It solves:

```text
u_t = u - u^3 - k - v + Du * Delta u
v_t = u - v + Dv * Delta v
```

The initial field is configurable:

- `init_mode=iid`: independent standard normal noise at each grid point.
- `init_mode=grf`: spatially correlated Gaussian random fields, the default.

Default time settings are `[0, 1]` with 10 saved intervals and 11 saved time
nodes, including both the `t=0` initial state and the `t=1` final state.
`tdim=11` is the number of saved frames, not 10.

Example GRF generation:

```bash
python data/DataGen/time_dependent/gen_rd.py \
  --save-path /large_storage/zhangxf/PDEdata/reaction_diffusion \
  --total-samples 1000 \
  --resolution 128 \
  --T 1.0 \
  --n-save-steps 10 \
  --init-mode grf
```

Example iid comparison generation:

```bash
python data/DataGen/time_dependent/gen_rd.py \
  --save-path /large_storage/zhangxf/PDEdata/reaction_diffusion \
  --total-samples 1000 \
  --resolution 128 \
  --T 1.0 \
  --n-save-steps 10 \
  --init-mode iid
```

For separate train/test files, use disjoint seed ranges, for example
`--split train --seed-offset 0` and `--split test --seed-offset 10000000`.
The helper script `data/DataGen/time_dependent/run_reaction_diffusion.sh` uses
that convention.

HDF5 layout:

```text
/{sample_id}/data      shape = (11, Ny, Nx, 2)
/{sample_id}/grid/x
/{sample_id}/grid/y
/{sample_id}/grid/t    shape = (11,)
```

Root and sample-group attrs include `Du`, `Dv`, `k`, `T`, `tdim`,
`n_save_steps`, `init_mode`, `init_mean`, `init_std`, `grf_length_scale`,
`grf_spectral_power`, `x_range`, and `y_range`. Each sample group also stores
its `seed`, and the file stores the `sample_seed` array. `grid/t` is
`np.linspace(0, 1, 11)` for the default run.

Use `--init-mode iid` to compare with older white-noise data. Use the default
`--init-mode grf` for smoother, spatially correlated initial conditions. Time
integration uses SciPy `solve_ivp` with adaptive RK45; the default saved
interval `0.1` is an output interval, not a fixed internal solver step.

#### Data generation for DarcyFlow Equation:

- Run the shell script:

```bash
bash data_gen/data_gen_NLE/ReactionDiffusionEq/run_DarcyFlow2D.sh
```

which will in turn run the python script
`data_gen/data_gen_NLE/ReactionDiffusionEq/reaction_diffusion_2D_multi_soluion_Hydra.py`

- Update `data_gen/data_gen_NLE/config/config.yaml` to:

```yaml
type: "ReacDiff" # 'advection'/'ReacDiff'/'burgers'/'CFD'
dim: 2
```

- Finally, run the data merge script:

```bash
python data_gen/data_gen_NLE/Data_Merge.py
```

#### Data generation for 1D Advection Equation:

```
# generate data and save as .npy array
cd PDEBench/pdebench/data_gen/data_gen_NLE/AdvectionEq

# Either generate a single file
CUDA_VISIBLE_DEVICES='2,3' python3 advection_multi_solution_Hydra.py +multi=beta1e0.yaml

# Or generate all files
bash run_trainset.sh
```

- Update `data_gen/data_gen_NLE/config/config.yaml` to:

```yaml
type: "advection" # 'advection'/'ReacDiff'/'burgers'/'CFD'
dim: 1
savedir: "./save/advection"
```

```
# serialize to hdf5 by transforming npy file
cd ..
python Data_Merge.py
```
